## About

I'm a full-stack engineer focused on the unglamorous parts of software that decide whether a product survives contact with real users: data modeling, authentication, API design, and deployment.

My work centers on **Welile**, where I build tools for markets that mainstream software has largely ignored — vehicle owners tracking maintenance and service history, and landlords and tenants coordinating without spreadsheets and group chats. Each product starts as a problem I've watched people work around manually.

I ship across the stack because small products don't have the luxury of specialists. That means I write the React Native screen, the API it calls, the schema behind it, and the deploy pipeline that puts it in front of users.

## Building at Welile

> Welile exists to make everyday services — owning a car, renting a home — legible and manageable from a phone.

<table>
<tr>
<td width="55%" valign="top">

### Welile Car Platform

The web backbone of the Welile vehicle ecosystem: service management, customer records, and the operational tooling that keeps the mobile app supplied with real data.

**Problem** — Vehicle service providers run on paper logs and WhatsApp threads, so service history vanishes the moment a customer switches garages.

**Approach** — A typed TypeScript codebase over a normalized relational schema, with vehicle records as the single source of truth shared across web and mobile clients.

`TypeScript` `React` `Node.js` `PostgreSQL`

[**Repository →**](https://github.com/Joshwanda17/welile-car-platform)

</td>
<td width="45%" valign="top">

### Welile Car Companion

The consumer-facing React Native app: vehicle profiles, maintenance records, and service booking in the owner's pocket.

**Problem** — Owners lose track of what was serviced, when, and by whom.

**Approach** — Cross-platform React Native client backed by the Car Platform API, with offline-tolerant local state so the app stays usable on unreliable connections.

`React Native` `JavaScript` `Expo`

[**Repository →**](https://github.com/Joshwanda17/welile-car-companion)

</td>
</tr>
</table>
